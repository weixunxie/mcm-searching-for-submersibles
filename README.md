# Mathematical Contest in Modeling (MCM) 2024 – Searching for Submersibles

This repository contains our team’s submission for the 2024 Mathematical Contest in Modeling (MCM), **“Searching for Submersibles.”** The project focused on building quantitative models to support search and rescue planning for a missing submersible under uncertain ocean conditions.

## Project Summary
In this project, we developed a modeling framework to address several key components of the search process, including:
- predicting the likely position of the submersible over time
- evaluating search equipment options under different operating constraints
- designing efficient search paths
- extending the approach into a more generalizable search framework

The work combined mathematical modeling, scenario-based reasoning, and quantitative analysis to structure a complex real-world problem with incomplete information and uncertainty.
